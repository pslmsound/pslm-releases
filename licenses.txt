The full notice also ships inside every copy of PSLM, so you do not need a
network connection to read it:

    macOS   PSLM.app/Contents/Resources/THIRD_PARTY_LICENSES.txt
            (right-click PSLM in Applications, Show Package Contents)
    iOS     Settings > Third-Party Licenses, inside the app

-----------------------------------------------------------------------------
Why this file is a pointer and not the licences themselves:

This URL is compiled into shipped PSLM builds, so it has to keep resolving. It
cannot redirect, because GitHub Pages serves .txt as plain text and a plain
text file has no way to send a browser anywhere.

It is a pointer rather than a second copy of the licences because a second copy
is exactly what went wrong before. This file sat here naming the wrong publisher
in the written offer above for weeks after the bundled document was corrected,
because nothing kept the two in step. The live page is now generated from the
canonical THIRD_PARTY_LICENSES.txt at deploy time and cannot disagree with the
file inside the app. Please do not paste the licence text back here.
